## 3 设置 centos7 本身 网络环境
```
# 一共要修改以下三个文件
     /etc/sysconfig/network-scripts/ifcfg-ens33
     /etc/hostname
     /etc/hosts
```

#### /etc/sysconfig/network-scripts/ifcfg-ens33 的修改
```
...
    # 修改 dhcp 改为 static
    BOOTPROTO="static"
    ...
    
    # 新增
    IPADDR=192.168.10.100  #这个是本机的ip
    GATEWAY=192.168.10.2
    DNS1=192.168.10.2
```

#### /etc/hostname 的修改 改为想要的本机的名称
```
hadoop100
```

#### /etc/hosts 的修改，即ip映射
```
192.168.10.100 hadoop100
```
