### 知识点：
```
异或运算性质：
    
    交换律，即 a ^ b ^ c = a ^ c ^ b
    结合律， 即 (a ^ b) ^ c = a ^ ( b ^c )
    对于任何数，都有 a ^ a = 0, a ^ 0 = a
    自反性， a ^ b ^ b = a ^ 0 = a
    
    
    那么根据交换律
    y = b^x  那么可以推导出 x= b^y = y^b
    例子python：
    b = 3
    x = 5
    y = b^x
    # y = 6
    print (y)
    # t=b^y
    t = 3^6
    print(t)
    # t = 5 = x
    # t=y^b
    t = 6^3
    print(t)
    # t = 5 = x
```
