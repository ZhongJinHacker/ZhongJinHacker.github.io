#### JAVA 源码
```java
...
    String str1 = packedSwitch(1);
    ...
    
    private String packedSwitch(int i) {
            String str = null;
            switch (i) {
                case 0:
                    str = "she is a baby";
                    break;
                case 1:
                    str = "she is a girl";
                    break;
                case 2:
                    str = "she is a woman";
                    break;
                case 3:
                    str = "she is an obasan";
                    break;
                default:
                    str = "she is a person";
                    break;
            }
            return str;
        }
```
