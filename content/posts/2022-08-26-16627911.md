### 项目中用到的模块 API
```
# 模块：
    import pandas as pd
    import numpy as np
    from scipy.optimize import curve_fit
```

#### numpy
```
np.array     创建ndarray
    np.polyfit   根据传入的x数组和y数组，及阶数，拟合出一个多项式函数（得到的是系数k和偏执b）
    np.poly1d 根据  np.polyfit输出，得到可用的函数
    np.corrcoef 返回两个数组的相关性系数
```

#### pandas
```
pd.Series  创建带标签的一维数组，默认从0开始加序号
```

#### scipy.optimize
```
curve_fit  数据曲线拟合
    返回值： popt为拟合得到的参数,pcov是参数的协方差矩阵
```
