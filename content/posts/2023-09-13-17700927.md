给定一个二叉树 root ，返回其最大深度。

二叉树的 最大深度 是指从根节点到最远叶子节点的最长路径上的节点数。

示例 1：  
![image](https://img2023.cnblogs.com/blog/1267154/202309/1267154-20230913215833251-809181718.jpg)

输入：root = [3,9,20,null,null,15,7]  
输出：3  
示例 2：

输入：root = [1,null,2]  
输出：2

#### 解题思路

这里可以转化思路为

  1. 计算当前节点 左子树的深度 和 右子树的深度
  2. 判断哪个深度值更大，然后加上自己这个节点（自己算一层深度为1），即加一，为当前树的深度
  3. 那么利用递归的思想，就可以从最底层的节点，层层向上累加，即可得到这棵树的最大深度

```java
/**
     * Definition for a binary tree node.
     * public class TreeNode {
     *     int val;
     *     TreeNode left;
     *     TreeNode right;
     *     TreeNode() {}
     *     TreeNode(int val) { this.val = val; }
     *     TreeNode(int val, TreeNode left, TreeNode right) {
     *         this.val = val;
     *         this.left = left;
     *         this.right = right;
     *     }
     * }
     */
    class Solution {
        public int maxDepth(TreeNode root) {
            int depth = 0;
            if (root == null) {
                return depth;
            }
    
            depth = 1;
            int leftDepth = maxDepth(root.left);
            int rightDepth = maxDepth(root.right);
            return depth += leftDepth > rightDepth ? leftDepth : rightDepth;
        }
    }
```
