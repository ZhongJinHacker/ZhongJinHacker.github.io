给你一棵二叉树的根节点 root ，翻转这棵二叉树，并返回其根节点。

示例 1：  
![image](https://img2023.cnblogs.com/blog/1267154/202309/1267154-20230912083009551-308770745.jpg)

输入：root = [4,2,7,1,3,6,9]  
输出：[4,7,2,9,6,3,1]

#### 这题比较简单

#### 解题思路

  1. 查询root 节点是不是null ，如果是就直接返回
  2. 将root的左子节点和右子节点调换一下
  3. 然后递归调用invertTree，并分别传入左子节点和右子节点即可

```java
/**
     * Definition for a binary tree node.
     * public class TreeNode {
     *     int val;
     *     TreeNode left;
     *     TreeNode right;
     *     TreeNode() {}
     *     TreeNode(int val) { this.val = val; }
     *     TreeNode(int val, TreeNode left, TreeNode right) {
     *         this.val = val;
     *         this.left = left;
     *         this.right = right;
     *     }
     * }
     */
    class Solution {
        public TreeNode invertTree(TreeNode root) {
    
            if (root == null) {
                return null;
            }
    
            TreeNode tmp = root.left;
            root.left = root.right;
            root.right = tmp;
            invertTree(root.left);
            invertTree(root.right);
    
            return root;
        }
    }
```
