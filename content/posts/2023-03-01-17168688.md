#### 6\. 再看`sub_1A40`和`sub_181C`

在sub_181C 中看到全局数组`unk_2B00`, 取前面几个值`63 7C 77 7B F2 6B 6F C5` 搜索引擎搜索，发现是AES的sbox表，说明这里是AES算法特征，github搜索AES算法实现，发现代码与`https://github.com/dhuertas/AES`类似`sub_1A40`对应`init`, `sub_181C`对应`expansion`，`sub_1AA4`对应`aes_cipher`

#### 9 编写注册机
```python
import hashlib
    from Crypto.Cipher import AES
    import base64
     
    input = "1234567890"
    hl = hashlib.md5()
    hl.update(input.encode("utf-8"))
    md5_data = hl.hexdigest()
     
    key = '64746179796473216474617979647321'
    key = bytes.fromhex(key)
    aes = AES.new(key, AES.MODE_ECB)
    
    aes_en = aes.encrypt(bytes.fromhex(md5_data))
    l = [hex(int(i)) for i in aes_en]
    print(" ".join(l))
    encrypted_text = str(base64.encodebytes(aes_en), encoding='utf8').replace('\n', '')
    print(encrypted_text)
```
